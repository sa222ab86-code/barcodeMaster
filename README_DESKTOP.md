# دليل تشغيل وبناء تطبيق طباعة الملصقات كبرنامج سطح مكتب مستقل (EXE) 🖥️📦

تمت تهيئة المشروع وتطويره ليدعم التحويل الكامل إلى تطبيق سطح مكتب يعمل على نظام ويندوز (Windows Desktop Application) من خلال مكتبة **Electron** المتكاملة ومحزم البرامج **electron-builder**.

---

## 🚀 كيفية بناء ملف الـ EXE وتشغيله على جهازك خطوة بخطوة

### الخطوة 1: تثبيت بيئة العمل (Node.js) ⚙️
إذا واجهت مشكلة `'npm' is not recognized` في سطر الأوامر، فهذا يعني أن بيئة **Node.js** غير مثبتة على جهازك أو تحتاج إلى تفعيل المسار الخاص بها.
1. اذهب إلى الموقع الرسمي وقم بتحميل وتثبيت النسخة المستقرة الموصى بها (LTS):
   👉 [https://nodejs.org/](https://nodejs.org/)
2. أثناء التثبيت، تأكد من وضع إشارة صح على خيار **"Add to PATH"** (إضافة إلى متغيرات المسار).
3. بعد اكتمال التثبيت، **قم بإغلاق نافذة سطر الأوامر (CMD) وافتح واحدة جديدة** لتحديث المتغيرات.

---

### الخطوة 2: تثبيت حزم المكتبات 📦
افتح نافذة سطر الأوامر (CMD) داخل مجلد المشروع، ثم اكتب الأمر التالي لتثبيت مكتبات النظام بما فيها حزم الـ Desktop:
```bash
npm install
```

---

### الخطوة 3: تجربة تشغيل التطبيق محلياً 🧪
إذا كنت ترغب في تشغيل واجهة البرنامج كمتصفح عادي أو كتطبيق سطح مكتب فوري للتجربة بدون بناء ملف EXE نهائي:

* **للتشغيل الفوري المباشر (نسخة الويب):**
  ```bash
  npm run dev
  ```
  *(ثم افتح الرابط الظاهر: `http://localhost:3000`)*

* **لتشغيل نافذة سطح مكتب للتجربة (Electron):**
  ```bash
  npm run electron:start
  ```

---

### الخطوة 4: تحويل المشروع إلى تطبيق EXE مستقل واحترافي 🎉

لحل مشكلة **"لا يعد تطبيقاً صحيحاً على win32"** (والتي تحدث عند تشغيل برنامج مكتوب لنواة 64-بت على نظام تشغيل ويندوز 32-بت)، قمنا بتوفير خيارات بناء مخصصة تدعم النواتين بالكامل:

#### 1️⃣ الخيار الأول: بناء نسخة متوافقة مع جميع الأجهزة (32-بت / 64-بت) ⭐ [موصى به لحل المشكلة]
هذا الأمر سينتج لك تطبيقاً يعمل على **أي جهاز ويندوز** (سواء كان نظام التشغيل لديك 64-بت أو 32-بت القديم):
```bash
npm run electron:build:32
```
*سيعطيك هذا الخيار ملفين في مجلد المخرجات:*
*   نسخة محمولة ومتوافقة بالكامل: `...-ia32-portable.exe`
*   معالج تثبيت متوافق بالكامل: `...-ia32.exe`

#### 2️⃣ الخيار الثاني: بناء نسخة مخصصة لويندوز 64-بت فقط (64-bit)
إذا كنت متأكداً أن جهازك والأجهزة الأخرى تعمل بنظام ويندوز 64-بت حصراً وترغب بالاستفادة القصوى من أداء المعالجات الحديثة:
```bash
npm run electron:build:64
```
*سيعطيك هذا الخيار ملف المحمول وملف التثبيت للنواة 64-بت فقط.*

#### 3️⃣ الخيار الثالث: بناء جميع النسخ معاً (للنواتين 32-بت و 64-بت) دفعة واحدة
بناء جميع الملفات لجميع الأجهزة والأنظمة:
```bash
npm run electron:build
```

---

## 📂 أين ستجد ملفات الـ EXE التي تم بناؤها؟
بعد انتهاء عملية البناء بنجاح، سيقوم المحزم بإنشاء مجلد جديد في جذر مشروعك باسم:
### **`dist_electron`**

ستجد داخله ملفات الـ EXE بأسماء واضحة بحسب النواة التي تم بناؤها:
*   **الملفات التي تنتهي بـ `ia32.exe` أو `ia32-portable.exe`**: هي التي تعمل على كافة الأنظمة (32-بت و 64-بت) وهي الحل الأكيد للمشكلة التي واجهتك.
*   **الملفات التي تنتهي بـ `x64.exe` أو `x64-portable.exe`**: مخصصة فقط لأنظمة 64-بت.

---

## ✨ ميزات نسخة سطح المكتب المضافة:
1. **واجهة نظيفة وخالية من مشوشات المتصفح**: تم إخفاء القوائم وتجذير التطبيق ليكون مستقلًا ومرنًا.
2. **روابط نسبية آمنة**: تم ضبط آلية البناء (Vite Base path) لدعم بروتوكول الملفات المحلي للويندوز بشكل ممتاز لتجنب الشاشة البيضاء.
3. **أداء سلس ومتجاوب**: يعمل بالكامل أوفلاين مع إيقاف أي دورة تحديثات زائدة لحفظ موارد جهازك (CPU).
