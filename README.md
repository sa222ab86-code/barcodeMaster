# باركود ماستر | BarCode Master 🏷️💼

> **نظام متكامل واحترافي لطباعة ملصقات الباركود والأسعار وإدارة عروض الأسعار الذكية وربط الأنظمة السحابية والمحلية.**

---

## 🌟 الميزات الرئيسية (Key Features)

### 🏷️ 1. تصميم وطباعة ملصقات الباركود
- دعم مختلف أنواع الباركود (Code 128, EAN-13, UPC, Code 39, QR Code وغيرها).
- قوالب جاهزة ومتعددة لمقاسات الرول الحراري (Roll Gap) والورق المقسم (A4 Sheet).
- تحكم كامل ودقيق في أبعاد الملصق، حجم الخطوط، الهوامش، والعملة (ريال سعودي مع الرمز الرسمي).
- إمكانية رفع شعار المتجر وإخفائه/إظهاره بمرونة.

### 💼 2. إدارة وإصدار عروض الأسعار الذكية
- إنشاء وتخصيص عروض الأسعار والفواتير المبدئية بنموذجين: (نموذج حراري 80mm و نموذج A4 رسمي).
- **منع الصفحات الفارغة تماماً:** طباعة وتصدير PDF مضبوطة على صفحة واحدة بدقة عالية.
- صندوق مخصص في إعدادات المنشأة للتحكم في الشروط والأحكام الثابتة وتضمينها تلقائياً.
- **مشاركة واتساب:** زر لمشاركة تفاصيل عرض السعر مباشرة عبر تطبيق واتساب بنص منسق.
- تفقيط المبالغ باللغة العربية واحتساب ضريبة القيمة المضافة (VAT) تلقائياً.

### 🔌 3. التكامل والربط التقني (ERP & Database Sync)
- مزامنة مرآتية ذكية مع قواعد بيانات SQLite المحلية لبرامج نقاط البيع والمحاسبة.
- تكامل مباشر وسحابي مع منصات ERP الشهيرة (دفترة - Daftra، الأستاذ - Al-Ostad).
- دعم جلب واستيراد المنتجات تلقائياً، والتعامل الذكي مع كود SKU كمعرف بديل.
- استيراد وتصدير قوائم المنتجات عبر ملفات Excel (XLSX).

### ⚡ 4. التحديث التلقائي الذكي المباشر (OTA Updates)
- نظام فحص تلقائي للإصدارات الجديدة عبر الإنترنت دون الحاجة لنقل البرنامج على فلاشة USB.
- إمكانية التحديث المباشر من نفس الجهاز وحفظ كافة الإعدادات والمنتجات تلقائياً.

## 🚀 متطلبات التشغيل والبدء السريع (Getting Started)

### المتطلبات الأساسية:
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم `npm`

### خطوات التثبيت والتشغيل:

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/YOUR_USERNAME/react-barcode-printer.git
   cd react-barcode-printer
   ```

2. **تثبيت الحزم البرمجية (Install dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل بيئة التطوير المحلية (Run Development Server):**
   ```bash
   npm run dev
   ```
   *سيعمل التطبيق على الرابط:* `http://localhost:3000`

## 🖥️ بناء نسخة سطح المكتب المستقلة (Electron Desktop App)

يمكن تشغيل وبناء التطبيق كبرنامج EXE مستقل لنظام ويندوز:

- **لتشغيل وضع سطح المكتب التطويري:**
  ```bash
  npm run electron:dev
  ```

- **لبناء ملف التثبيت المكتبي (Installer / EXE):**
  ```bash
  npm run electron:build
  ```
  *أو لنظام 64-bit:*
  ```bash
  npm run electron:build:64
  ```

## 📂 هيكلة المشروع (Project Structure)

```text
├── src/
│   ├── components/         # المكونات الرئيسية (App, QuotationManager, LabelCard, VersionUpdateModal, etc.)

├── main.cjs                # مدخل تطبيق سطح المكتب (Electron Main Process)
├── preload.cjs             # وسيط حماية إلكترون والطباعة الصامتة
└── package.json            # إعدادات الحزم وسكربتات التشغيل
```
